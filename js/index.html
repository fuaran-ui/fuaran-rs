fuaran-rs — browser-native (wasm32) client

The Rust host decodes, renders, and drives a Fuaran UI wire tree entirely client-side: the codec + server-parity renderer + apply engine compiled to wasm32, mounted by a thin hand-written loader (no framework, no wasm-bindgen). The controls below drive the session (state write-back + a tree-op), and the mount re-renders from the WASM module.
