# fuaran

This crate is a **placeholder**. It exports nothing and never will.

The Fuaran UI wire-format host for Rust is published as **`fuaran-ui`**:

```sh
cargo add fuaran-ui
```

Repository: <https://github.com/fuaran-ui/fuaran-rs>. Documentation:
<https://docs.rs/fuaran-ui>. The bare name is held so that `fuaran` cannot be
taken by an unrelated project and mistaken for that host — the same posture the
unscoped npm name `fuaran` takes beside the `@fuaran-ui/*` packages.
